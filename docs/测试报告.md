## 7. 指标口径说明

1. 图像来源：simulator/synth.py 逐帧合成（位置/旋转/缩放/亮度/噪声全随机，seed 固定可复现）；
2. "检出率"以件为单位（该帧存在任一注入缺陷且被判 NG）；"类型检出率"以缺陷实例为单位；
3. 定位误差对照对象是合成器输出的解析真值（非人工测量）；
4. 节拍为 Python 进程内 perf_counter 计时的 定位+检测 全链路耗时，不含图像落盘与网络传输；
5. 以上均为仿真环境数据，真实相机/光源/PLC 下需重新标定与验收。
