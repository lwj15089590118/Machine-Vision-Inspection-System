# 验收清单（逐条打勾用）

> 使用方式：按顺序执行命令，对照"预期结果"打勾。全部通过即视为交付验收
> 通过。所有指标口径均为仿真验证值。

## 0. 环境安装

- [ ] `python --version` 输出 3.12.x
- [ ] `.venv\Scripts\activate` 后 `pip install -r requirements.txt` 无报错
- [ ] 版本核对：opencv-python 5.0.0.93 / numpy 2.5.1 / flask 3.1.3 / pymodbus 3.6.9

## 1. 相机标定（calib/）

- [ ] 删除 `data/calib/calibration.json` 后运行 `python calib/calibrate.py`
- [ ] 控制台输出 20 张棋盘格生成与角点误差日志，无异常退出
- [ ] 重投影误差 RMS ≤ 0.5px（参考实测 0.092px）
- [ ] 像素当量实测 ≈0.100 mm/px，末尾两行验收结论均为 PASS
- [ ] 生成 `data/calib/chess/board_01..20.png` 与 `undistort_demo.png`

## 2. 合成器（simulator/）

- [ ] `python simulator/synth.py --count 10 --defects --seed 42` 成功输出 10 帧
- [ ] `data/truth/*.json` 与图像同名成对存在；缺陷统计行打印各类型数量
- [ ] 同参数重跑一次，两张图逐像素一致（可复现性）
- [ ] 抽查任一 JSON：center_px/angle_deg/defects 字段齐全

## 3. 定位（locate/）

- [ ] `python locate/locate.py --image data/images/frame_000001.png --truth-dir data/truth`
      打印定位结果并生成 `data/annot/loc_*.png` 标注图（绿圆+红键槽线）
- [ ] 单张中心/角度误差与真值同数量级（中心 <0.5px、角度 <1° 级）
- [ ] 批量模式 `--image-dir data/images --truth-dir data/truth` 打印误差统计表

## 4. 缺陷检测（detect/）

- [ ] `python detect/detect.py --image data/images/frame_000002.png`
      输出结果 JSON + "真值对照"行 + 生成 `insp_*.png` 标注图
- [ ] NG 帧的 defect_types 与真值类型一致或包含

## 5. 批量验收（run_batch.py）

- [ ] `python run_batch.py --save-annot 6` 跑完 500 帧（约 1 分钟）
- [ ] 五项门槛全 PASS：检出率≥95%、误报率≤5%、中心 P95≤0.3mm、角度 P95≤0.8°、节拍≤400ms
      （参考实测：100% / 0% / 0.033mm / 0.466° / 73.8ms；节拍为墙钟
      计时，逐次浮动属正常，以门槛为准）
- [ ] 退出码为 0（`echo $LASTEXITCODE`）
- [ ] 自动生成 `docs/测试报告.md`（含混淆矩阵、类型检出率、错检明细）
- [ ] `data/batch_report.json` 可被程序读取且字段完整
- [ ] `data/annot/batch_*.png` 标注图肉眼可查验

## 6. PLC 链路（plc_link/）

- [ ] 终端 A 启动 `python plc_link/plc_server.py --seed 42`，
      出现"[PLC-SIM] 从站已就绪"与"[VISION] 主循环启动"
- [ ] 终端 B 运行 `python plc_link/modbus_client_test.py` → **10/10 全 PASS**
- [ ] 看门狗项显示约 2s 后 HR2=999
- [ ] 故障后恢复正常触发仍 PASS
- [ ] 客户端退出码 0；服务端打印每次检测记录与真值对照
- [ ] `data/records.jsonl` 追加记录、`data/annot/latest.png|latest.json` 更新

## 7. 看板（dashboard/）

- [ ] 保持终端 A 运行，另开终端执行 `python dashboard/app.py`
- [ ] 浏览器打开 `http://127.0.0.1:5001` 页面正常渲染（若改过 DASH_PORT 以 config 为准）
- [ ] 当前帧标注图随检测更新（mtime 变化才刷新）
- [ ] 良率仪表盘 / 节拍曲线 / NG 饼图有数据
- [ ] 最近 50 条记录表出现，NG 行红色、OK 行绿色
- [ ] 点击"手动触发检测"→ 提示写入 HR0=1 → 数秒后总数 +1、图表刷新
- [ ] 关闭终端 A 后再点触发按钮：页面提示无法连接视觉服务（降级不崩溃）
